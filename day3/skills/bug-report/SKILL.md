# Bug Report

When creating a bug report, follow this procedure:

1. Identify the problem in one concise title.
2. Summarize the actual behavior in 1-2 sentences.
3. State the expected behavior.
4. Provide numbered reproduction steps.
5. Include environment details when available:
   - OS
   - application/version
   - browser/device
6. Assign severity:
   - Critical: system unusable, data loss, or major security impact.
   - High: major feature is broken with no reasonable workaround.
   - Medium: important functionality is affected but a workaround exists.
   - Low: minor issue with limited impact.
7. List evidence or error messages if provided.
8. Do not invent missing technical details.
9. Keep the report under 300 words.
10. Use clear, neutral, technical language.
